## 🧩 Sobre o projeto

Este é um slider interativo que apresenta cinco personagens de um universo de RPG com temática cyberpunk/tecnológica. Cada personagem possui uma imagem de fundo (versão desktop e mobile), nome e descrição. A navegação é feita por meio de botões circulares com ícones, que alternam entre os personagens com um efeito visual de seleção.

O projeto foi desenvolvido com foco em design responsivo e transições suaves, utilizando apenas HTML, CSS e JavaScript puro.

---

<br>

## ✨ Funcionalidades

- **Slider de personagens** – exibe um personagem por vez, com fundo e informações.
- **Navegação por botões** – clique nos ícones circulares para alternar entre os personagens.
- **Design responsivo** – adapta-se a telas de desktop, tablets e smartphones.
- **Efeitos visuais** – destaque do botão selecionado com escala e sombra colorida personalizada para cada personagem.
- **Imagens adaptativas** – uso de `<picture>` com `source` para carregar imagens específicas para desktop e mobile, otimizando o carregamento.

---

<br>

## 🛠️ Tecnologias utilizadas

- **HTML5** – estrutura semântica.
- **CSS3** – estilização, animações e layout responsivo (Flexbox, gradientes, media queries).
- **JavaScript (ES6)** – lógica de navegação e manipulação de classes.

## 🎮 Como interagir
- Navegar – clique em um dos botões circulares (com ícones) localizados no canto direito (ou na parte inferior em dispositivos móveis) para alternar entre os personagens.
- Visualizar – ao selecionar um personagem, sua imagem de fundo, nome e descrição são exibidos em destaque.
